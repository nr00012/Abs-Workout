# Abs Workout

Six-Pack Tracker: a personal workout app (installable PWA). Cable-machine plan, daily done log, streak, weight/BMI, waist, heart rate and blood pressure, with sourced healthy-range targets.

Your data is stored on the phone (browser storage). This repository holds only the app code, never personal data.

## Install

1. Turn on GitHub Pages: repo Settings, Pages, Source "Deploy from a branch", branch `main`, folder `/ (root)`.
2. Open `https://nr00012.github.io/Abs-Workout/` on your phone.
3. Android Chrome: menu, **Install app**. iPhone Safari: Share, **Add to Home Screen**.
